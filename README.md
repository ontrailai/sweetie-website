# Sweet Bee Honey — website

Design mockup for the Sweet Bee Honey website (raw local honey, San Diego).

## What's in `mockup/`

These are the design files from the "Sweet Bee Homepage Mockup" canvas made in Claude:

- `Main.dc.html` / `Mobile.dc.html` — homepage (desktop / phone)
- `Product.dc.html` / `ProductPhone.dc.html` — product page (desktop / phone)
- `Batches.dc.html` / `BatchesPhone.dc.html` — batches page (desktop / phone)
- `Jar.dc.html` — the No. 01–06 jar
- `canvas.json` — canvas layout
- `ds/sweetbee/tokens.json` — brand colors and type

They're design source files, not a finished site yet: they open in Claude's design viewer, and the logo and photos stay in the Claude canvas.

Next step: convert these pages into a plain HTML/CSS site that can be hosted on GitHub Pages.
